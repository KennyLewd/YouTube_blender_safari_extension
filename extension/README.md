# Ambient Light for Safari: extension folder

Load this folder in Safari with **Develop → Add Temporary Extension…**, or convert it into a Mac app with `xcrun safari-web-extension-converter`. See the [main README](../README.md) for installation, settings and troubleshooting.

Based on Ambient light for YouTube by Wessel Kroos (MIT). See [LICENSE](LICENSE) and [UPSTREAM.md](../UPSTREAM.md).
